# Portfolio Projects

This repository contains two web development projects showcasing different design approaches and functionalities.

## Projects

### 1. Cups & Croccery - Premium Pottery & Glassware E-commerce Site

A beautifully designed e-commerce website for a premium pottery and glassware store. The site features a handmade, artisanal aesthetic with clay and mud-inspired color palettes, creating an authentic ceramic studio atmosphere.

#### Features
- **Responsive Design**: Optimized for all devices with mobile-first approach
- **3D Product Visualization**: Integrated Model Viewer for interactive product displays
- **Handmade Aesthetic**: Clay and mud color scheme with texture overlays
- **Smooth Animations**: Vanilla Tilt for 3D card effects and scroll reveals
- **Premium Typography**: Custom fonts (Playfair Display, Inter) for elegant presentation
- **Background Integration**: Pottery studio background image with noise texture for handmade feel

#### Technologies Used
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (Vanilla Tilt, Model Viewer)
- Google Fonts
- Font Awesome Icons

#### Color Palette
- Primary: Raw Terracotta (#8C4A32)
- Secondary: Dark Earth (#4A3B32)
- Background: Sandy Clay (#F4EFEB)
- Accent: Ochre Glaze (#C08A62)

### 2. Multitasker - Productivity Dashboard

A modern, animated productivity dashboard designed for multitasking and task management. Features a dark theme with dynamic red accents and floating particle animations.

#### Features
- **Dark Theme**: Sleek black background with red accent colors
- **Dynamic Animations**: Floating particles, moving lines, and gradient shifts
- **Responsive Grid Layout**: Adaptive card-based design
- **Smooth Transitions**: CSS animations for interactive elements
- **Modern Typography**: Poppins font for clean readability
- **Particle Effects**: Animated background elements for visual interest

#### Technologies Used
- HTML5
- CSS3 (Animations, Gradients, Grid Layout)
- JavaScript (for potential interactivity)
- Google Fonts (Poppins)

#### Color Scheme
- Background: Pure Black (#000000)
- Text: White (#ffffff)
- Accent: Red (#ff0000)
- Cards: Dark Gray (#1a1a1a)

## How to View

1. Clone the repository:
   ```bash
   git clone https://github.com/sabiquekhan11/cupsandcroccery.git
   ```

2. Navigate to the project directory:
   ```bash
   cd project
   ```

3. Open the HTML files in your browser:
   - For Cups & Croccery: Open `cupsandcroccery.html`
   - For Multitasker: Open `project.html`
